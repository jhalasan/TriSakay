Not yet exercised on a real device.
- Ride history (`app/(tabs)/history.tsx`, `src/store/useHistoryStore.ts`) — real `get_passenger_trip_history` security-definer RPC (`docs/SCHEMA.MD` §4.3d, mirroring the driver app's `get_driver_trip_history`), joining the passenger's completed/cancelled `ride_requests` with driver name and `transactions` payment info (both LEFT JOINs, null-safe for rides cancelled before assignment/payment). Store exposes `{items, loading, error, load()}`; the tab has pull-to-refresh via `usePullToRefresh`. Not yet exercised on a real device.
- Payment history screen (`app/profile/payment-history.tsx`) — new screen, reads the same `useHistoryStore`/RPC as ride history, filtered to `paymentStatus === 'paid' || 'refunded'` (pending/failed/absent payments don't belong in "history"), showing route/date/fare with a payment-method badge (GCash/Cash) and a status badge (Paid=green/Refunded=blue). Linked from `app/profile/payment-methods.tsx`'s new "Payment history" nav row. Not yet exercised on a real device.
- Notifications (`app/notifications.tsx`, `src/store/useNotificationsStore.ts`) — real `subscribeToNotifications`/`markAllNotificationsRead` from the already-shared `packages/services/src/notifications` module (same service the driver app uses), wired session-wide via a new `useNotificationsSync` hook in `app/_layout.tsx` (subscribes on `sessionUserId`, not just while the Notifications screen is mounted, since `home.tsx`'s unread-count badge needs live data everywhere). Mock `src/mocks/notifications.ts` deleted. New `apps/passenger/tests/notificationsStore.test.ts` (4 tests, mirrors the driver's own store test). Not yet exercised on a real device.

**🟡 Partial (UI real, data fake or missing):**
- Settings (`app/(tabs)/settings.tsx`) — toggles and the language cycler are in-memory only, no persistence or real i18n.
- Complaint submission (`app/(tabs)/complaints.tsx`) — free-text form only, `wait(600)` fake submit, no `complaints` insert. The "related trip" picker now calls `useHistoryStore.load()` on mount so it isn't permanently empty.

**❌ No code at all:**
- Password reset (both apps' "Forgot password?" are `Alert.alert` stubs).

Two spec divergences to resolve, not silently pick a side on:
- **Map library:** CONTEXT §3 specifies MapLibre; the actual implementation (`packages/ui/src/components/OsmMap`) is Leaflet inside a `react-native-webview`, using OSMF's free tile service — which the component's own `mapHtml.ts` documents as dev/low-volume only, not production-safe.
- **`supabase/` directory:** CONTEXT §3's repo structure lists one at the root; none exists. Supabase MCP `apply_migration` is still the only applied path — there are no migration files in version control (see `docs/SCHEMA.MD`'s header note).
