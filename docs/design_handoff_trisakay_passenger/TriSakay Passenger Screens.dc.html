Five tabs, 60px bar, white on a hairline — the active tab is navy with a 22×3 marker on the top edge, never a filled pill, so the bar stays quiet under the navy headers. System states reuse one anatomy: 46px tile, title, one line of plain-language cause, then a single primary action; failure never borrows the emergency red, which stays reserved for SOS. The offline strip is the only element allowed to sit above the header band.
