REDESIGN Driver — Accepted ride (trip/active)
What's hard today
Each passenger card carries up to six controls at once (Arrived, cash toggle, Cancel, Start/Complete, Transfer, Release), so the next step is hard to spot while driving. Complete stays grey with no reason given until cash is toggled. The only navigation control is a small icon on the map, and it doesn't say where it goes. End trip always shows but is disabled while passengers are aboard. SOS takes a full-width slot in every state.
What changes
The sheet leads with the next stop's address and a labelled Navigate button. Each passenger gets one big primary action that follows their status: I've arrived, then Start ride, then Collect cash, then Complete drop-off. The hint under it explains any disabled state. Transfer, Release and Cancel move behind a ⋯ menu. SOS becomes a fixed hold button on the map, and End trip only appears once everyone is dropped off. Call and Message sit on the passenger strip: Call opens the phone dialer, Message opens one-tap quick replies (4d). Try it in 4a.
