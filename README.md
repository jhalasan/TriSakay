# TriSakay Monorepo

This workspace is organized for three apps:
- Passenger app: Expo React Native
- Driver app: Expo React Native
- Admin web app: React + Vite

## Scripts

- npm run start:passenger
- npm run start:driver
- npm run dev:admin
- npm run build:admin
- npm run typecheck

## Structure

- apps/passenger
- apps/driver
- apps/admin
- packages/shared
- packages/services
- packages/ui
- packages/utils
- supabase
- docs
